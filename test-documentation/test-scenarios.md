# Test Scenarios

## 1. Homepage
- TS-001: Verify that the homepage loads successfully.
- TS-002: Verify that all homepage sections are displayed correctly.
- TS-003: Verify that images and other visual elements load correctly.

## 2. Navigation
- TS-004: Verify that all navigation links work correctly.
- TS-005: Verify that the correct page opens after clicking each navigation link.
- TS-006: Verify that the logo redirects to the homepage.

## 3. Buttons and Interactive Elements
- TS-007: Verify that all buttons perform their intended actions.
- TS-008: Verify that interactive elements respond to user input.

## 4. Forms
- TS-009: Verify that forms accept valid input.
- TS-010: Verify that required fields are validated.
- TS-011: Verify that invalid email formats are rejected.
- TS-012: Verify that appropriate feedback is displayed after form submission.

## 5. Responsive Design
- TS-013: Verify the website layout on desktop screens.
- TS-014: Verify the website layout on tablet screens.
- TS-015: Verify the website layout on mobile screens.
- TS-016: Verify that no unwanted horizontal scrolling occurs.

## 6. UI and Usability
- TS-017: Verify text readability and visual consistency.
- TS-018: Verify element alignment and spacing.
- TS-019: Verify that images and icons are displayed correctly.

## 7. Browser Compatibility
- TS-020: Verify the website in Google Chrome.
- TS-021: Verify the website in Mozilla Firefox.
- TS-022: Verify the website in Microsoft Edge.
