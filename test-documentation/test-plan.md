# Test Plan

## 1. Project Overview

This project focuses on manual QA testing of a live business website to evaluate its functionality, usability, responsiveness, and overall user experience.

## 2. Testing Objectives

- Identify functional and visual defects.
- Verify that website features work as expected.
- Evaluate website responsiveness across different screen sizes.
- Check form validation and user interactions.
- Document test results and report identified defects.

## 3. Scope of Testing

Testing will cover:

- Website navigation and links
- Buttons and interactive elements
- Forms and input validation
- UI and usability
- Responsive design
- Basic browser compatibility

## 4. Testing Types

- Functional Testing
- UI Testing
- Usability Testing
- Responsive Testing
- Exploratory Testing
- Compatibility Testing

## 5. Tools

- Google Chrome
- Chrome DevTools
- GitHub
- Google Sheets / Excel

## 6. Test Environment

To be documented during testing.

## 7. Test Execution

Test cases, actual results, and identified defects will be documented throughout the project.

## 8. Risks and Limitations

Testing will be performed on the live website. Destructive actions and operations involving real user data will be avoided unless explicitly authorised.
